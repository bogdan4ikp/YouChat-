YouChat — версия с серверной частью

Что изменилось в этой версии:
- Мессенджер переименован: теперь это YouChat (бывшее имя Aurora осталось только во
  внутренних идентификаторах: папка aurora-src, ключ localStorage, id баннера).
- Вход только через Яндекс ID: на экране входа одна большая кнопка «Войти через Яндекс ID».
  Имя, аватар и (если Яндекс отдал) дата рождения подтягиваются из профиля Яндекса.
  Для работы нужны YANDEX_CLIENT_ID, YANDEX_CLIENT_SECRET и PUBLIC_URL — инструкция
  в server/README.md.
- Входа по логину и паролю больше нет: формы регистрации и пароля убраны с экрана входа,
  а серверные адреса /api/auth/register и /api/auth/login отвечают 403. Новый аккаунт
  появляется только после успешной авторизации через Яндекс ID.
- Выход из аккаунта: пункт «Выйти из аккаунта» в меню профиля удаляет сессию, чистит
  cookie и возвращает на экран входа с кнопкой Яндекса. Без сервера приложение больше
  не пускает внутрь: вместо этого показывает экран входа с подсказкой.
- Экран входа переработан: тёмное стекло, живой фон, градиентный заголовок, аккуратная
  кнопка Яндекса, понятные ошибки OAuth (отмена, неверные ключи, устаревшая сессия).
- Новый логотип: сине-фиолетовый градиентный знак вместо прежней «арки». Он стоит
  в левой колонке, в шапке панели бесед, на экране входа и в иконке вкладки браузера.
  Картинка встроена прямо в стили (assets/logo.jpg + tools/embed-logo.js), поэтому
  автономный YouChat.html показывает логотип без внешних файлов.
- Онбординг после Яндекс ID: при первом входе открывается экран «Давайте знакомиться».
  Имя и фото подставляются из Яндекса, короткий адрес (@username) генерируется
  автоматически на основе имени (латиница + цифры) и проверяется на занятость.
  О себе и дата рождения — необязательно; можно поставить своё фото профиля и баннер
  (своё изображение или один из готовых). После «Начать общение» профиль сохраняется
  и человек попадает в мессенджер, повторно заполнять ничего не нужно.
- Если аккаунт уже создан (повторный вход через Яндекс ID), онбординг не показывается —
  человек сразу попадает в свои беседы.
- Пункт «Сбросить данные» в меню профиля заменён на «Выйти из аккаунта».
- Появился настоящий сервер: server/server.js на Node.js без внешних зависимостей.
  Данные (пользователи, группы, сообщения, вложения) хранятся в SQLite на сервере,
  а не в памяти телефона или браузера.
- Регистрация и вход по @username и паролю; пароль хранится как scrypt-хеш, сессия —
  HttpOnly-cookie на 30 дней.
- Сообщения, реакции, закрепления, правки, удаления, профиль и роли сохраняются на сервере
  и проверяются на права при каждом запросе.
- Реальное время через SSE: новое сообщение, заявка или смена ролей сразу видны всем
  участникам без перезагрузки страницы.
- Группы настоящие: владелец, админы с правами, заявки на вступление, передача владения,
  исключение участников, журнал действий — всё синхронизируется между людьми.
- Поиск людей по короткому адресу: кнопка «Найти людей» в верхней части панели бесед,
  а также ссылка /u/<username>.
- Ссылки /g/<handle> открывают вступление в группу: открытая — сразу, закрытая — заявкой.
- Фото, видео, голосовые и кружки загружаются на сервер и доступны всем участникам беседы.

Что исправлено в поведении интерфейса:
- Усилены проверки назначения и снятия роли администратора.
- Передача владения разрешена только реальному участнику группы; владелец всегда один.
- Владелец не может покинуть группу, пока не передаст владение.
- Некорректные и повторные заявки обрабатываются без дублей.
- Убраны фиктивные пользователи и демонстрационные заявки — вместо них реальные люди.
- Плавные анимации интерфейса сохранены, системная настройка уменьшения движения
  учитывается.
- Обновлены и модульная версия (aurora-src), и автономный файл YouChat.html.

Как запустить:
- Требуется Node.js 22.5+ (используется встроенный node:sqlite). npm install не нужен.
- Команда: node server/server.js, затем открыть http://localhost:8080
- Порт и адрес задаются переменными PORT и HOST.
- Яндекс ID: YANDEX_CLIENT_ID, YANDEX_CLIENT_SECRET, PUBLIC_URL.
- Подробности развёртывания, nginx и резервных копий — в server/README.md.

Режим без сервера:
- Если открыть YouChat.html как файл или сервер недоступен, приложение переходит в локальный
  режим и хранит данные в браузере. На экране входа есть кнопка «Продолжить без сервера».

Ограничения:
- Одна SQLite-база на инсталляцию; для больших нагрузок нужен PostgreSQL — отдельная задача.
- Нет восстановления пароля для входа по логину; для Яндекс ID пароль не нужен.
- Сквозного шифрования нет: сервер видит сообщения.
- Лимиты: текст 4000 символов, файл до 140 МБ, запись до 1 минуты.

Проверки:
- Все JS-модули проходят node --check без синтаксических ошибок.
- Автономный HTML пересобран из актуальных модулей и стилей (tools/build-standalone.js).
- API проверено сквозным тестом: регистрация, вход, поиск по @username, личные сообщения,
  группы, роли, исключение, заявки, вложения, профиль, выход.
- Проверен редирект Яндекс ID: адрес авторизации, state-cookie, callback-адрес.
